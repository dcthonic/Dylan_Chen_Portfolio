# GitHub Pages upload

Upload the contents of `github-pages-upload.zip` to the repository root. Keep the `videos` folder and its four MP4 files together; the other images and PDFs belong beside `index.html`.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. The site is static and does not need a build step.
